An AI-powered text-to-image generation platform built using the MERN stack that allows users to generate high-quality images from text prompts using the Clipdrop API with a secure credit-based system.

# ✨ About

Imagix is a full-stack AI-powered image generation platform that transforms text prompts into images using the Clipdrop API. The application features secure user authentication, a credit-based image generation system, online payments through Razorpay, and a modern responsive interface.

# ⚙ Installation

Clone the repository

```bash
https://github.com/sanjaykumar9318/Imagix.git
```

Install dependencies

```bash
npm install
```

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ..
npm run dev
```

Create a `.env`

```env
MONGO_URL=

JWT_SECRET=

PORT=

CLIPDROP_API_KEY=

RAZORPAY_KEY_ID=

RAZORPAY_KEY_SECRET=
```
